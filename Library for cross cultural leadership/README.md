# 跨文化视野与领导力图书馆

一个可直接运行的中文静态网页应用：十四本跨文化、领导力与判断力经典，各自拥有独立的视觉语言与阅读编排，以原文摘录为骨架，配一个核心模型和一个一步实验。

## 运行

无需构建、无需安装依赖。

- 直接双击 `index.html`，或在项目目录启动任意静态服务器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:4173/>。

## 目录

```text
index.html                 首页方块矩阵
books/                     十四本独立书页
assets/css/base.css        共享底座、返回入口、清单与动效
assets/css/home.css        首页视觉
assets/css/book-*.css      十四种独立书页视觉语言
assets/js/books.js         核心模型、单步实验、清单状态
assets/js/site.js          页面揭示与指针响应
```

## 编排与交互

- 每页以原书短段落为主，再进入可操作模型；但先后顺序各书不同：
  有的先给模型再看原文（文化人类学、金字塔原理），有的先落到现场再进入模型（孙子兵法、无声的语言、认同等），有的把原文、练习与行动编成一条时间线、五条实践或两套系统。
- 每页保留一个核心模型，并新增一个一次点击或一次拖动就能完成的实验。总互动模型不超过两个，避免用动画替代理解。
- 模块起点使用 CSS proximity scroll snap；模块内部仍可自由滚动。启用 `prefers-reduced-motion` 时会关闭入场动效。
- 所有行动清单在刷新后清空；不使用 localStorage 保存进度。
- 支持键盘操作与可见焦点。外部依赖为零，字体使用系统字体栈。

## 阅读说明

页面中的引文尽量保留原书措辞；跨语种引文为忠实转译。每页的按语、场景与判断是编辑性延伸，不是原书替代。请在真实决策中验证，并回到原书继续阅读。
