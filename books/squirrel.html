01

原文 / ACORN

注意力只对
“与我有关”开门。

五段原文，按 A / C / O / R / N 排。

当听众倾听时，是在倾听对于他们来说重要的、所需要的和跟自己有关系的内容。
A

Audience / 听众

了解你的听众不仅仅是了解听众的个人资料。尽管有时候了解年龄范围、姓名、职位、教育程度等信息是有帮助的，但这些信息一般都不会成为一个真正强有力的 WIIFM。
C

Credibility / 可信性

能力通常被视为确立信誉的方式。你所具备的完成工作任务、处理某种情况的能力，以及长期以来所实现的显著成绩，都将会成为你声誉和个人信誉的一部分。
O

Order / 信息顺序

当信息具有较高的相关性时，将最为重要的信息或者关键信息放在开始的位置，对听众的影响最大。
R

Remember / 记住我

短小的信息能够吸引我们的注意力，易于了解，容易让人们记住。
N

Need for emotion / 情感需要

如果我们不能使听众的情感参与进来，我们就不能说服他们。

一步实验 / 翻译成他的橡果

同一项内部流程改造，说给天天被流程卡住的人听。

你的版本

“我们将上线一套新的端到端协同系统，提升流程标准化水平。”

先别解释系统。点一下，把这句话翻成他的橡果。

你的版本说的是系统；听众的橡果，是他每天少填几张表。

02

现场 / APPLY

同一个产品，
不同的橡果。

跨文化 / 路演

当听众倾听时，是在倾听对于他们来说重要的、所需要的和跟自己有关系的内容。

总部关心合规与回报，本地伙伴关心长期承诺和团队位置。同一套 PPT 讲两遍，等于让两边自己翻译。

给每类听众写一句“你会得到什么”，换一个他们熟悉的本地案例。

领导力 / 远程汇报

当信息具有较高的相关性时，将最为重要的信息放在开始的位置。

会议第一句是“今天汇报三件事”。镜头那头的人开始回消息。议程没有错，只是没有回答他们为什么现在要听。

标题写“周四前需要你决定 X”，正文第一段写清这件事与收件人的关系。

03

互动模型 / 橡果配方

把一条信息，
做成一颗橡果。

选听众，再挑一句开场、一个证据、一个画面。看它是否真的对准了对方的需要。
