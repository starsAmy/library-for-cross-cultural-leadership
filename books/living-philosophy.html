稻盛和夫 / 人生与工作的乘法

作为人，
何谓正确？

人生与工作的结果，
不只看你有多聪明。

“人生·工作的结果＝思维方式×热情×能力。”
方向一旦为负，才能与努力越大，结果越远离你想要的地方。

心MIND
01

原文 / THE EQUATION

一道
乘法题。

能力与热情都是正数。方向，是那个正负号。

因为思维方式有正负之分，所以，思维方式为负时，热情和能力越大，结果越是一个更大的负数。
人生 · 工作的结果 = 思维方式 × 热情 × 能力
01 / MIND

正负号

人生·工作的结果＝思维方式×热情×能力。

三项相乘。任何一项归零，结果就归零；方向为负，另外两项越强，偏离越远。

02 / SIX

六项精进

付出不亚于任何人的努力；要谦虚，不要骄傲；要每天反省；活着，就要感恩；积善行，思利他；不要有感性的烦恼。
03 / QUESTION

判断的原点

作为人，何谓正确？

不是“对公司是否有利”，也不是“别人会不会发现”。先回到这个更朴素的问题。

另一句原文 / NOTE

人生的意义在于提升心性，磨炼灵魂。

“敬天爱人”不是口号，它要求把对人的尊重放进每一次具体判断。

02

互动模型 / 人生方程式

同样的能力，
可以走向相反的方向。

移动三个变量。这个模型不预测人生，只帮你看清：方向、努力与能力如何相互作用。

+ 21 结果指数 / RELATIVE

方向为正，能力与热情正在形成复利。继续把“他人是否真正受益”放进判断。

仅用于理解乘法关系，不代表对人生的量化预测。

人生 · 工作的结果 = 思维方式×热情×能力

+50 × 60 × 70 / 10000 = 21

一步实验 / 作为人，何谓正确

合作方想买客户数据，报价足以补上本季缺口。没人会立刻发现。

先把问题从“能不能做”换成“该不该做”。这一步不保证你选对，但会让你看见自己正在选。

02

现场 / APPLY

利他之心，
要有跨文化的耳朵。

跨文化 / 领导力

积善行，思利他。

带着“为你好”的心态进入另一种文化，很容易把自己的成功标准当成对方的需要。帮助变成另一种自我中心。

先问：你最想解决什么？谁应该参与决定？我们何时该退出？

领导力 / 自我管理

不要有感性的烦恼。

业绩压力下，人很容易把聪明用在绕过规则或牺牲他人上。情绪会替你找一个“这次不一样”的理由。

写下三句：没人知道我会做吗？成本转给了谁？一年后我怎么解释？

今天结束之前 / SELF-CHECK

你的努力，
正在把人
带向哪里？

努力本身不是答案。方向、方法与对他人的真实影响，才是这个乘法里更难的部分。
