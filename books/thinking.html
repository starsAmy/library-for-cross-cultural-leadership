01

原文 / TWO SYSTEMS

两个系统，
同时在线。

左边快，右边慢。大多数时候，左边先交卷。

SYSTEM 1 / 快

自动作答

系统1的运行是无意识且快速的，不怎么费脑力，没有感觉，完全处于自主控制状态。

看到 2+2，答案自己出现。你不需要“决定”去知道它。

SYSTEM 2 / 慢

费力验算

系统2将注意力转移到需要费脑力的大脑活动上来，例如复杂的运算。

计算 17×24 时，你会屏住呼吸、停下脚步。它很可靠，也很懒。

WYSIATI / WHAT YOU SEE IS ALL THERE IS
你看到的就是全部。

系统1用手头的信息拼出一个连贯故事，再把故事当成完整现实。故事越顺，缺口越不容易被发现。

一步实验 / 换一种说法

同一种药，两种说法。你的第一反应会变吗？

“七成能成功。可以试。”

同一个事实，被放进了“得到”的框里。风险没有被删掉，只是退到了背景。

02

互动模型 / 直觉拦截器

先让直觉回答。
再看它错在哪里。

三道小题，不为难你。只为让你亲眼看见：那个“脱口而出的答案”是怎么出现的。

QUESTION 01 / 03

不要计算太久。先选你第一反应想选的。

一副球拍和一个球一共 1.10 美元。球拍比球贵 1.00 美元。球多少钱？

系统一先说 / FAST ANSWER

慢一步看 / SLOW CHECK

答对不是目的。看见抢答的那一秒，才是。

03

现场 / APPLY

让系统二，
只在关键处上班。

跨文化 / 解释别人

你看到的就是全部。

同事在会上没说话，你立刻写下“他不认同”。这个解释来得太顺，顺到你没有检查缺口。沉默也可能是在等私下沟通。

写下三个替代解释，各找一个能验证的事实。把“我猜他”改成“我需要确认”。

领导力 / 重大决策

风险界定是一种权力运作。

谁定义“风险”，谁就决定了讨论的边界。团队越一致，越容易把彼此赞同当成证据。

讨论前独立写判断；开场先问“如果一年后失败，最可能的原因是什么”。
